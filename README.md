# Claude Code for PMs

This is the course workspace for Product School's "Claude Code for PMs"
certification, cohort ccpm-2026.1. Everything about Rook Industries in
this workspace is a fictional teaching scenario — it's not a real company.

## Getting started

1. Click **Use this template** at the top of this page, then **Create a
   new repository**.
2. On your new copy, click **Code → Download ZIP**.
3. Unzip the folder wherever you keep your files.
4. Open that folder in the Claude desktop app.

## What's in here

- **00-rook** — background on Rook Industries: the company, the product,
  the team, and the release you're stepping into. Reference material for
  every module.
- **01-origin-story** through **06-sidekicks** — the six course modules,
  in order.

Each module folder has a `prompts.md` file. That's where your work goes —
paste in the prompts you write for that module as you go, so by the end
you have a library of your own prompts to look back on.
